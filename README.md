# Interactive Digital Story: THE ANTS!!
This is my senior comprehensive project, using a combination of hand-drawn illustrations, adapted texted from the story, and interactive techniques, I wanted to explore how making a story interactive can heighten and evoke negative emotions like fear, anxiety, and discomfort.

# Instructions
1. Download the repository
2. Open repository folder
3. Open begin.html with Chrome
4. Have fun!

You can view the story with this link (in Chrome) : https://github.com/naomibl/comps
